# Fibonacci Task Estimation Guidelines

Use these Fibonacci point values to estimate tasks:

| Estimate | Difficulty | Guidelines and examples |
|---|---|---|
| **1 Point** | Very easy | Fix a typo, update UI text, or change one configuration line. Quick to complete. |
| **2 Points** | Easy | Create a simple UI component or write a short piece of logic using an existing example. |
| **3 Points** | Medium | Implement a familiar feature, such as a basic CRUD API or a registration form with validation. |
| **5 Points** | Hard | Requires additional research, complex logic, or complex database interactions. |
| **8 Points** | Very hard / Too large | Set up a new module, integrate a third-party payment gateway, or handle a task with unclear technical requirements. |

**Recommendation:** When a task reaches **8 Points**, break it into smaller tasks in Linear.
